# Tesla Stock Price Prediction using LSTM

A machine learning project for analyzing historical Tesla stock data and forecasting stock prices using a Long Short-Term Memory (LSTM) neural network.

## Technologies Used

* Python
* TensorFlow / Keras
* Pandas
* NumPy
* Matplotlib
* yFinance
* Scikit-learn

## Project Overview

This project collects historical Tesla stock market data, preprocesses the data, trains an LSTM deep learning model, and generates stock price predictions.

## Features

* Historical Tesla stock data collection
* Data preprocessing and normalization
* LSTM-based time-series forecasting
* Actual vs. predicted price visualization
* Stock price analysis

## Disclaimer

This project is created for educational purposes. Stock-price predictions are not guaranteed to be accurate and should not be considered financial advice.
